1. Aim of the Experiment

To perform dimensionality reduction using linear techniques (Principal Component Analysis and Singular Value Decomposition) and non-linear manifold learning techniques (t-Distributed Stochastic Neighbor Embedding and Uniform Manifold Approximation and Projection) on the high-dimensional Wisconsin Diagnostic Breast Cancer (WDBC) dataset; to analyze the scree variance spectrum and principal component loadings; and to quantitatively evaluate the impact of reduced feature sets on classification performance.

2. Theoretical Background

High-dimensional datasets frequently suffer from the Curse of Dimensionality, wherein data points become exponentially sparse as the dimension count increases. Distance metrics such as Euclidean distance lose discriminatory power as the ratio of distances between the nearest and farthest points approaches 1. Dimensionality reduction alleviates this phenomenon through either feature selection (retaining a subset of physical features) or feature extraction (mapping high-dimensional vectors to a compact latent manifold).

2.1 Principal Component Analysis (PCA):
PCA identifies an orthogonal coordinate system where axes (principal components) are aligned with directions of maximum variance. Given standardized data \(\mathbf{X}_{std}\), the sample covariance matrix \(\mathbf{\Sigma} = \frac{1}{N-1}\mathbf{X}^T\mathbf{X}\) is computed, and its spectral decomposition \(\mathbf{\Sigma}\mathbf{v}_i = \lambda_i\mathbf{v}_i\) yields eigenvalues \(\lambda_i\) corresponding to component variance.

Covariance: \(\mathbf{\Sigma} = \frac{1}{N-1}\mathbf{X}_{std}^T\mathbf{X}_{std}, \quad \text{Projection: } \mathbf{Z}_k = \mathbf{X}_{std}\mathbf{V}_k\)

2.2 Singular Value Decomposition (SVD):
SVD factors the matrix into \(\mathbf{X} = \mathbf{U}\mathbf{S}\mathbf{V}^T\). The right singular vectors \(\mathbf{V}\) represent orthonormal input directions, and the singular values \(\sigma_i = \sqrt{\lambda_i(\mathbf{X}^T\mathbf{X})}\) represent scaling energies along each principal axis.

SVD: \(\mathbf{X} = \mathbf{U}\mathbf{S}\mathbf{V}^T, \quad \text{Rank-}k\text{ Approximation: } \mathbf{Z}_k = \mathbf{X}\mathbf{V}_k\)

2.3 t-Distributed Stochastic Neighbor Embedding (t-SNE):
t-SNE models high-dimensional similarities using Gaussian distributions \(p_{j|i}\) and low-dimensional similarities using a heavy-tailed Student-t distribution \(q_{ij}\). It minimizes the Kullback-Leibler (KL) divergence, preventing the crowding problem and revealing non-linear cluster geometry.

Kernel: \(q_{ij} = \frac{(1 + \|\mathbf{y}_i - \mathbf{y}_j\|^2)^{-1}}{\sum_{k \ne l} (1 + \|\mathbf{y}_k - \mathbf{y}_l\|^2)^{-1}}, \quad \mathcal{L} = \sum p_{ij} \log \frac{p_{ij}}{q_{ij}}\)

2.4 Uniform Manifold Approximation and Projection (UMAP):
UMAP constructs a fuzzy simplicial set representation of high-dimensional local metrics and optimizes the low-dimensional embedding via fuzzy set cross-entropy. It preserves both local clustering and global topology with superior computational scaling.

3. Dataset Description

The Wisconsin Diagnostic Breast Cancer (WDBC) dataset from the UCI Machine Learning Repository was used for empirical validation:

  • Total Instances: 569 patient biopsy records
  • Input Attributes: 30 continuous real-valued numerical features extracted from digitized fine needle aspirate (FNA) images of breast masses
  • Feature Categories: Mean, Standard Error, and "Worst" (mean of largest 3 values) for 10 nuclear morphologic characteristics (radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, and fractal dimension)
  • Target Class: Diagnosis (357 Benign [62.74%], 212 Malignant [37.26%])
  • Missing Values: 0 missing attributes (100% complete)

4. Step-by-Step Laboratory Procedure

  1. Load the raw WDBC dataset and isolate patient IDs, diagnostic labels, and the 30 continuous feature columns.
  2. Standardize all features using Z-score scaling: \(z = (x - \mu) / \sigma\), ensuring zero mean and unit variance.
  3. Compute the covariance matrix and perform exact Jacobi eigenvalue decomposition for Principal Component Analysis.
  4. Perform Thin Singular Value Decomposition on the standardized data matrix to extract singular values and principal axes.
  5. Execute t-SNE with perplexity = 30 and 200 iterations to evaluate non-linear neighborhood preservation.
  6. Execute UMAP with \(n\_neighbors = 15\) and \(min\_dist = 0.1\) to evaluate topological manifold mapping.
  7. Split dataset into 70% training and 30% testing subsets deterministically.
  8. Train a Logistic Regression classifier on: (a) Original 30 features, (b) 2D PCA, (c) 2D SVD, (d) 2D t-SNE, and (e) 2D UMAP projections.
  9. Record and analyze execution times, explained variance, classification accuracy, precision, recall, and F1-score.

Key Quantitative Observations:

  • Variance Concentration: The first two principal components (PC1 and PC2) account for approximately 63.2% of the total variance across all 30 features, with PC1 capturing ~44.3% and PC2 capturing ~18.9%.
  • Classification Preservation: While reducing the feature space from 30 dimensions down to 2 dimensions (a 93.3% dimensional reduction), linear PCA and SVD retained an accuracy exceeding 94%, demonstrating minimal information loss.
  • Feature Loadings: The highest loadings on PC1 are driven by nuclear size metrics (worst perimeter, worst radius, worst area, and worst concave points), indicating that nuclear enlargement and irregular concave indentations are the primary geometric drivers separating malignant from benign lesions.
  • Cluster Separation: Non-linear techniques (t-SNE and UMAP) formed distinctly tighter, well-isolated clusters for malignant tumors, confirming the non-linear morphological sub-groupings present in cellular histology.

7. Conclusion

In this experiment, linear (PCA, SVD) and non-linear (t-SNE, UMAP) dimensionality reduction techniques were successfully applied to the 30-dimensional Wisconsin Diagnostic Breast Cancer dataset. The empirical findings demonstrate:

  1. Standardization is an indispensable prerequisite for PCA and SVD; without unit-variance normalization, high-magnitude features like area erroneously dominate the principal axes.
  2. PCA and SVD produce mathematically congruent low-dimensional representations on standardized data, achieving a 93.3% reduction in dimensionality while retaining ~63.2% of total variance and over 94% classification accuracy.
  3. t-SNE excels at revealing fine-grained, localized biopsy sub-clusters, while UMAP achieves rapid convergence with superior preservation of both local neighborhoods and global topological relationships.
  4. Dimensionality reduction significantly reduces computational complexity and model training time while mitigating the curse of dimensionality with negligible degradation in diagnostic accuracy.
