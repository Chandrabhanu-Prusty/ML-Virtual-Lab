Dimensionality Reduction Using PCA, SVD, t-SNE & UMAP

Experiment Aim

To apply linear (PCA, SVD) and non-linear (t-SNE, UMAP) dimensionality reduction techniques on a high-dimensional biomedical dataset (Wisconsin Diagnostic Breast Cancer, 30 features), analyze feature contributions, visualize low-dimensional manifold projections, and evaluate the empirical impact of reduced representations on classification accuracy.

Section 02

Theoretical Foundations

Mathematical background on the curse of dimensionality, linear projection techniques, and non-linear manifold learning.

Curse of Dimensionality

Foundational Problem
As the number of features \( D \) grows, the volume of the feature space increases exponentially (\( V \propto r^D \)), causing the available data points to become extremely sparse. In high-dimensional spaces, pairwise Euclidean distances converge to a uniform constant, degrading distance-based metrics (KNN, clustering, SVM) and increasing overfitting risk.
Distance Concentration Effect: \(\lim_{D \to \infty} \frac{\text{dist}_{\max} - \text{dist}_{\min}}{\text{dist}_{\min}} \to 0\)

Selection vs Extraction

Methodology
Feature Selection picks a subset of the original features without alteration (e.g. Mutual Information, RFE), preserving physical interpretability.

Feature Extraction transforms the original \( D \)-dimensional space into a new \( k \)-dimensional coordinate system (\( k \ll D \)) by constructing composite variables that retain maximal variance or manifold topology.
Transformation Mapping: \(f: \mathbb{R}^D \to \mathbb{R}^k \quad \text{where } k \ll D\)

Principal Component Analysis (PCA)

Linear / Orthogonal
PCA finds orthogonal axes (principal components) along which the variance of the data is maximized. It constructs the sample covariance matrix \( \mathbf{\Sigma} \) and computes its spectral decomposition.
Covariance & Eigenvalues: \(\mathbf{\Sigma} = \frac{1}{N-1} \mathbf{X}_{std}^T \mathbf{X}_{std}, \quad \mathbf{\Sigma} \mathbf{v}_i = \lambda_i \mathbf{v}_i\) Explained Variance: \(EVR_i = \lambda_i / \sum_j \lambda_j\)
Advantages
  • Global variance preservation
  • Fast exact analytical solution
  • Zero hyperparameters
Limitations
  • Linear transformations only
  • Sensitive to feature scaling
  • Assumes orthogonal variance

Singular Value Decomposition (SVD)

Linear / Factorization
SVD factors any real matrix into three constituent matrices \( \mathbf{X} = \mathbf{U} \mathbf{S} \mathbf{V}^T \). Truncated SVD provides the optimal low-rank matrix approximation according to the Eckart-Young-Mirsky theorem.
Matrix Factorization: \(\mathbf{X} = \mathbf{U} \mathbf{S} \mathbf{V}^T, \quad \mathbf{Z}_k = \mathbf{X} \mathbf{V}_k = \mathbf{U}_k \mathbf{S}_k\) Singular Energy: \(\sigma_i = \sqrt{\lambda_i(\mathbf{X}^T \mathbf{X})}\)
Advantages
  • Optimal low-rank approximation
  • Handles rectangular & sparse matrices
  • Directly related to PCA
Limitations
  • Constrained to linear hyperplanes
  • Computationally heavier for huge N

t-Distributed Stochastic Neighbor Embedding

Non-Linear / Manifold
t-SNE converts high-dimensional Euclidean distances into conditional probabilities \( p_{j|i} \) (Gaussian) and low-dimensional distances into probabilities \( q_{ij} \) (Student-t with 1 degree of freedom). It minimizes the Kullback-Leibler (KL) divergence via gradient descent.
Kernel Probabilities & Loss: \(q_{ij} = \frac{(1 + \|\mathbf{y}_i - \mathbf{y}_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|\mathbf{y}_k - \mathbf{y}_l\|^2)^{-1}}\) Loss: \(KL(P || Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}\)
Advantages
  • Resolves crowding problem
  • Reveals intricate non-linear clusters
  • Exceptional exploratory visualization
Limitations
  • Does not preserve global distances
  • \(O(N^2)\) computational cost
  • Cannot project new unseen points

Uniform Manifold Approximation & Projection

Non-Linear / Topological
UMAP assumes the data lies on a local Riemannian manifold with locally constant metric. It constructs a fuzzy simplicial set representation in high dimensions and optimizes a corresponding low-dimensional layout using fuzzy set cross-entropy.
Fuzzy Cross-Entropy Loss: \(C = \sum_{e} \mu(e) \log \frac{\mu(e)}{\nu(e)} + (1 - \mu(e)) \log \frac{1 - \mu(e)}{1 - \nu(e)}\)
Advantages
  • Preserves both local AND global structure
  • Orders of magnitude faster than t-SNE
  • Supports embedding out-of-sample points
Limitations
  • Hyperparameter sensitivity (n_neighbors)
  • Stochastic non-deterministic optimization

Section 03

Laboratory Procedure

Follow these sequential laboratory steps to execute dimensionality reduction, visualize latent features, and benchmark machine learning performance.

01

Load High-Dimensional Dataset

Acquire the official UCI Wisconsin Diagnostic Breast Cancer (WDBC) dataset comprising 569 patient biopsy samples.

02

Separate Features and Target Labels

Parse the raw CSV: isolate the diagnosis label column (\( M \) = Malignant, \( B \) = Benign) and extract the 30 continuous numerical morphological features.

03

Verify Data Integrity & Missing Values

Inspect for missing, NaN, or corrupted values. The UCI WDBC dataset is complete with 0 missing entries across all 569 records.

04

Standardize Features via Z-Score Normalization

Compute mean \(\mu_j\) and sample standard deviation \(\sigma_j\) for each of the 30 features. Standardize each value: \(z_{ij} = (x_{ij} - \mu_j) / \sigma_j\). This prevents features with large numeric scales (e.g., area) from dominating variance.

05

Apply Principal Component Analysis (PCA)

Calculate the 30×30 sample covariance matrix. Solve eigenvalues and eigenvectors using the Jacobi rotation algorithm. Project samples onto the top 2 and 3 principal components.

06

Apply Singular Value Decomposition (SVD)

Compute the Gram matrix \(\mathbf{X}^T \mathbf{X}\) and decompose into singular values and right singular vectors. Project data into optimal low-rank coordinates.

07

Apply t-SNE Non-Linear Manifold Embedding

Compute pairwise high-dimensional Gaussian joint probabilities with user-specified perplexity. Optimize Student-t low-dimensional coordinates via gradient descent.

08

Apply UMAP Fuzzy Simplicial Set Learning

Construct the k-nearest neighbor fuzzy simplicial set graph and project onto low-dimensional space using cross-entropy minimization.

09

Visualize Latent Embeddings

Generate interactive 2D and 3D Plotly scatter plots color-coding Benign (green) and Malignant (red) classes to inspect cluster separation.

10

Train Classifier & Compare Accuracy

Split dataset into 70% train and 30% test sets. Train a Logistic Regression classifier on: (1) original 30 features, and (2) reduced feature representations. Compare Accuracy, Precision, Recall, and F1-score.
